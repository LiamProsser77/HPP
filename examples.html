Learn LanScript by exploring simple programs.

Hello World

The classic first program. 

<lanscript>
<pro>
<start>

yes.put. "Hello World"

<script>
<end>

Creating a Name

Use name. to create a name. 

<lanscript>
<pro>
<start>

name. "LanScript"

yes.put. "Welcome to LanScript"

<script>
<end>

Using Text Formatting

Change how words appear using commands. 

<lanscript>
<pro>
<start>

yes.put. "LanScript"

.up

yes.put. "PROGRAMMING"

.down

yes.put. "programming"

<script>
<end>
